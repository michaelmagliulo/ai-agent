# AI Agent

A containerized Python project for developing and testing a personal AI agent.

An AI agent built in Python from first principles.

The goal of this project is to understand how AI agents work internally by building an agent without relying on high-level frameworks like LangChain.

---

## Clone the repository

```bash
git clone https://github.com/yourusername/ai-agent.git
cd ai-agent
```

---

## Open in VS Code

Open the project in VS Code and reopen it in the Dev Container when prompted.

---

## Configure your API key

Create a `.env` file in the project root:

```text
OPENAI_API_KEY=your_api_key_here
```

---

## Run the agent

```bash
python agent_with_narrative.py
```

Example:

```text
You: What time is it in London?
```
